# 𓆩⛧𓆪 DACREATOR-MD ☠︎

**DACREATOR-MD** is a customized WhatsApp automation bot built with Node.js and Baileys. This fork includes a dual-session hosting entrypoint, owner controls, moderation, media tools and a Gothic-themed command menu.

## Commands

Use `.menu` or `.help` for the command list. Owner controls include `.private`, `.public`, `.mode`, `.demon on`, `.demon off`, and `.demonstatus`.

## Hosting

Install dependencies with `npm install` and run `npm start`. To start two sessions, set `PAIRING_NUMBERS` to two comma-separated international numbers and configure `OWNER_NUMBER` and `OWNER_NUMBERS`. Keep pairing codes and session credentials private. Store `FEI_DATA_DIR` persistently for compatibility with existing deployments.
